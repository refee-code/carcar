# IMU963RA 陀螺仪航向校准技术文档

## 1. 问题背景

`auto_pose.c` 使用 IMU 陀螺仪 Z 轴积分计算车辆航向：

```c
s_heading_deg += gyro_z_dps * dt_s;
```

原始输出存在比例误差，导致位置坐标偏转，路径地图失真。  
校准前：旋转 90° 物理角度，HX 仅变化 34.5°（误差约 -62%）。

---

## 2. 校准方法

### 测量步骤

1. 上电，等待屏幕显示菜单，HX 值稳定（约2秒）
2. 在地面标记车辆初始方向（贴胶带或对准直角）
3. 记录初始 `HX` 值
4. 精准旋转车辆 **90°**（1\~2 秒内完成，减少漂移干扰）
5. 等待屏幕刷新（约 0.2 秒），记录终止 `HX` 值

### 校准系数公式

```
new_scale = old_scale × (90 ÷ |ΔHX|)
```

## 4. 最终配置

### auto_config.h

```c
/* 陀螺仪比例校正：实测 90° 旋转 → 86.9°，scale=1.03 修正后误差 3.1%（3.1°） */
#define AUTO_SEEKFREE_GYRO_SCALE  (1.03f)
```

### auto_seekfree_port.c — 应用位置

```c
#elif AUTO_SEEKFREE_USE_IMU963RA
    imu963ra_get_gyro();
    gyro_z_dps = imu963ra_gyro_transition(imu963ra_gyro_z)
                 * AUTO_SEEKFREE_GYRO_SCALE;
```

---

## 5. 注意事项

| 项目 | 说明 |
|------|------|
| 旋转参考 | 使用墙角、直角卡具等固定参考，确保 90° 精度 |
| 测量环境 | 车辆静止在水平地面，避免振动 |
| 温度影响 | 环境温度变化 > 20°C 时建议重新校准 |
| 磁力计使用 | `auto_seekfree_imu_reset_heading_from_mag()` 仅在**静止时一次性初始化**，车载电机磁场干扰较大，不适合连续融合 |
| 漂移误差 | 静止时 HX 仍会缓慢漂移（陀螺仪零偏），属正常现象，短时间路径跟踪影响可接受 |

---

## 6. 重新校准流程

若更换 IMU 或环境变化较大，按以下流程重新校准：

```
1. 将 AUTO_SEEKFREE_GYRO_SCALE 设为 1.0f
2. Clean + Build + 烧录
3. 上电，精准旋转 90°，记录 ΔHX
4. 计算新 scale = 90 ÷ |ΔHX|
5. 更新 AUTO_SEEKFREE_GYRO_SCALE，重新 Clean + Build + 烧录
6. 验证：旋转 90° 后 ΔHX 应在 88°\~92° 范围内
```
